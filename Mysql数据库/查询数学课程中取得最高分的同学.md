
### 步骤 1：确定数学课程的最高分









```sql
SELECT MAX(score) AS max_score
FROM grade
WHERE course = '数学';
```

### 步骤 2：关联查询取得该最高分的同学











```sql
SELECT stu_id
FROM grade
WHERE course = '数学' 
  AND score = (SELECT MAX(score) FROM grade WHERE course = '数学');
```

### 合并为一条 SQL（更简洁）











```sql
SELECT stu_id
FROM grade
WHERE course = '数学' 
  AND score = (SELECT MAX(score) FROM grade WHERE course = '数学');
```
