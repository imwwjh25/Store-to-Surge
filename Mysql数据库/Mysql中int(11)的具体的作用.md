### 问题 2：INT (11) 和 INT (5) 的核心区别

首先要明确一个**关键结论**：MySQL 中 `INT` 括号里的数字（如 11、5）**不是限制取值范围**，而是「**显示宽度（display width）**」，仅影响数字的**格式化显示**（需配合 `ZEROFILL` 关键字生效），不影响存储和取值范围。

#### 基础前提：INT 类型的本质

不管是 `INT(11)` 还是 `INT(5)`，底层存储都是 **4 个字节**，取值范围完全一致：

- 有符号（默认）：`-2147483648 ~ 2147483647`（约 ±21 亿）
- 无符号：`0 ~ 4294967295`（约 42 亿）

#### 两者的具体区别





|  类型   | 显示宽度 | 核心差异（仅 ZEROFILL 生效时） | 取值范围 | 存储字节 |
| :-----: | :------: | :----------------------------: | :------: | :------: |
| INT(11) |    11    |   不足 11 位时补 0 到 11 位    |  同 INT  |    4     |
| INT(5)  |    5     |    不足 5 位时补 0 到 5 位     |  同 INT  |    4     |

### 问题 3：为什么要设置显示宽度？不设置行不行？

#### 1. 显示宽度的作用（唯一场景）

显示宽度仅在 2 个条件同时满足时生效：

- 字段加了 `ZEROFILL` 关键字（补零）；
- 查询时需要格式化数字显示（比如固定位数的编号）。

如果不加 `ZEROFILL`，显示宽度**完全无意义**，插入 / 查询的数字都是原样显示。

#### 2. 不设置显示宽度行不行？

**完全可以**！

MySQL 中 `INT` 不指定显示宽度时，默认是 `INT(11)`（有符号）/ `INT(10)`（无符号），但这只是默认值，不影响任何功能。

#### 举个例子（理解显示宽度的作用）








```
-- 创建测试表：带ZEROFILL和不带的对比
CREATE TABLE test_int (
    int5_zerofill INT(5) ZEROFILL,  -- 显示宽度5，补零
    int11_zerofill INT(11) ZEROFILL,-- 显示宽度11，补零
    int5_no_zerofill INT(5),        -- 显示宽度5，不补零
    int_default INT                 -- 不指定宽度，默认INT(11)
);

-- 插入相同的值：100
INSERT INTO test_int VALUES (100, 100, 100, 100);

-- 查询结果
SELECT * FROM test_int;
```

查询结果：








| int5_zerofill | int11_zerofill | int5_no_zerofill | int_default |
| :-----------: | :------------: | :--------------: | :---------: |
|     00100     |  00000000100   |       100        |     100     |

**结论**：

- 只有 `ZEROFILL` + 显示宽度才会补零；
- 不加 `ZEROFILL` 时，`INT(5)`/`INT(11)`/ 默认 `INT` 显示效果完全一样。

### 问题 4：具体插入值的显示效果

#### 场景 1：INT (11) 插入 100 的显示效果

分两种情况：

- **不加 ZEROFILL**：查询显示 `100`（原样，和 `INT(5)`/ 默认 `INT` 无区别）；
- **加 ZEROFILL**：查询显示 `00000000100`（补零到 11 位）。

⚠️ 重要：`INT(11)` **不是存储 11 位数字**！它只是「显示宽度」，哪怕你存 10 位、12 位数字（只要在 INT 取值范围内），都能正常存储，显示时：

- 不加 ZEROFILL：原样显示（比如存 12345678901，显示 12345678901）；
- 加 ZEROFILL：补零到 11 位（比如存 12345，显示 00000012345）。

#### 场景 2：INT (5) 插入 100000（大于 99999）的显示效果

首先明确：`100000` 远小于 INT 的最大值（2147483647），所以**能正常存储**，显示效果分两种：

- **不加 ZEROFILL**：查询显示 `100000`（原样，哪怕超过显示宽度 5，也不会截断 / 报错）；
- **加 ZEROFILL**：查询显示 `100000`（因为数字位数 6 > 显示宽度 5，补零规则失效，直接显示原样）。

#### 补充：如果插入超过 INT 取值范围的数字

比如插入 `2147483648`（超过有符号 INT 最大值），不管是 `INT(5)` 还是 `INT(11)`，都会**直接报错**（因为超出存储范围，和显示宽度无关）：









```
ERROR 1264 (22003): Out of range value for column 'int5_zerofill' at row 1
```

### 总结

1. **核心本质**：INT (n) 中的 `n` 是「显示宽度」，不是存储长度 / 取值范围，所有 INT 类型都占 4 字节，取值范围一致；

2. **显示宽度的意义**：仅在 `ZEROFILL` 关键字配合时，补零到指定位数，否则无任何作用；

3. 显示效果规则 ：

   - 不加 ZEROFILL：所有 INT (n) 显示效果一致，插入值原样显示；
   - 加 ZEROFILL：不足 n 位补零，超过 n 位直接显示原值；

   

4. **选型建议**：无需刻意设置显示宽度，默认 INT 即可；若需要固定位数补零（如编号 0001、0002），再用 INT (n) ZEROFILL。
