### 一、先理清核心概念：分代 ZGC vs 不分代 ZGC

首先要明确「分代回收」的本质：

- **分代回收的核心逻辑**：基于「对象存活时间」将堆分为**新生代（Young Generation）** 和**老年代（Old Generation）**。新生代对象存活时间短、回收频率高（Minor GC），老年代对象存活时间长、回收频率低（Major GC）。
- **ZGC 的分代版本**：早期 ZGC（JDK 15-20）为了兼容传统 GC 的优化思路，提供了「分代 ZGC（Generational ZGC）」选项，试图通过分代进一步降低回收开销；
- **ZGC 的不分代版本**：Java 21 起默认的「不分代 ZGC」，不再划分新生代 / 老年代，而是对整个堆进行统一的并发标记、重定位和清理。

### 二、Java 21 为何将不分代 ZGC 设为默认？

ZGC 设计的核心目标是「超低延迟」，而分代回收反而与这个目标产生了冲突，这也是 Oracle 最终调整默认策略的核心原因：

#### 1. 分代 ZGC 的「额外开销」抵消了优势

分代回收的核心收益是「只回收新生代，减少每次 GC 扫描的内存范围」，但 ZGC 本身的特性让这个收益变得无意义：

- ZGC 的核心优势是**停顿时间仅与 GC 根集大小相关，与堆大小无关**，即使扫描整个 TB 级堆，停顿仍能控制在 10ms 内；
- 分代 ZGC 需要维护「跨代引用」（新生代对象引用老年代对象，反之亦然），引入了额外的「记忆集（Remembered Set）」维护开销，反而增加了应用线程的写屏障成本，降低了吞吐量；
- 分代 ZGC 需处理「晋升失败（Promotion Failure）」等分代特有问题，增加了 GC 逻辑复杂度，可能引入额外的停顿风险。

#### 2. 不分代 ZGC 更贴合 ZGC 的设计哲学

ZGC 的核心技术是「着色指针（Colored Pointers）」和「Region 化内存管理」：

- **Region 化管理**：ZGC 将堆划分为大小可变的 Region（2MB/32MB / 大 Region），回收时只需处理「存活对象少的 Region」，本质上已经实现了「细粒度回收」，无需再通过分代划分；
- **着色指针**：通过指针标记对象状态，可并发完成对象的重定位，不分代模式下逻辑更简单，并发执行效率更高，停顿时间更可控。

#### 3. 实测数据支撑：不分代 ZGC 表现更优

Oracle 官方测试数据显示：

- 不分代 ZGC 的**吞吐量比分代 ZGC 高 5%-10%**（减少了记忆集维护、跨代引用处理的开销）；
- 不分代 ZGC 的**最大停顿时间比分代 ZGC 低 10%-20%**（逻辑简化，减少了分代特有阶段的停顿）；
- 仅在「堆极小（<4GB）且新生代对象占比极高」的场景下，分代 ZGC 才有微弱优势，但这并非 ZGC 的目标场景（ZGC 面向大堆）。

### 三、Java 21 中 ZGC 分代模式的使用方式

虽然不分代是默认，但 Java 21 仍保留了分代 ZGC 的选项（仅用于特殊场景），启用方式如下：

bash



运行









```
# Java 21 启用分代 ZGC（需显式指定）
java -XX:+UseZGC -XX:+ZGenerational -Xms16g -Xmx16g YourApplication
```

**何时需要手动启用分代 ZGC？**

- 堆内存极小（<4GB）且应用产生大量临时对象（如高频创建短生命周期的字符串、集合）；
- 从老版本 ZGC（JDK 17/19）迁移，且已验证分代 ZGC 更适配你的业务；
- 注意：该场景更推荐使用 G1，而非 ZGC。

### 四、对实际应用的影响

1. **无需修改配置**：升级到 Java 21 后，只需 `-XX:+UseZGC` 即可启用优化后的不分代 ZGC，无需额外参数；
2. **性能表现更稳定**：不分代模式下，ZGC 的停顿时间、吞吐量波动更小，适合对稳定性要求高的核心系统（如金融交易、电商支付）；
3. **监控指标简化**：无需再关注「新生代 GC 次数」「老年代 GC 时间」等分代指标，只需监控「ZGC 总停顿时间」「Region 回收频率」即可。

### 总结

1. Java 21 中 ZGC 默认关闭分代回收，核心原因是不分代模式更贴合 ZGC 的低延迟设计目标，且能提升吞吐量、降低停顿；
2. 分代 ZGC 仅保留用于极小堆、临时对象极多的特殊场景，需手动通过 `-XX:+ZGenerational` 启用；
3. 实际使用中，Java 21 的不分代 ZGC 是大堆、低延迟场景的最优选择，无需额外配置即可获得比老版本分代 ZGC 更好的性能。
