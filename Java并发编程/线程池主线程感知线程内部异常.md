## 核心结论

线程池中的线程**默认会把异常 “吃掉”**，不会抛到主线程，主线程完全感知不到。

必须**主动处理**，主线程才能拿到异常。

------

# 4 种主线程感知线程异常的方案（面试必背）

## 1. **try-catch 包裹 run () /call () 方法（最基础）**

直接在任务内部捕获异常，手动处理。

java



运行









```
// Runnable 任务
Runnable task = () -> {
    try {
        // 业务逻辑
        int i = 1 / 0;
    } catch (Exception e) {
        // 异常在这里捕获，主线程可通过日志/共享变量感知
        System.err.println("线程内部异常：" + e.getMessage());
    }
};
executor.execute(task);
```

**优点**：简单直接

**缺点**：每个任务都要写 try-catch，不通用

------

## 2. **使用 Future.get () 捕获异常（最常用、面试首选）**

**submit () 提交任务 → Future.get () 会抛出 ExecutionException**，主线程可以捕获。

java



运行









```
Future<?> future = executor.submit(() -> {
    int i = 1 / 0; // 抛异常
});

try {
    future.get(); // 主线程阻塞等待，会抛出异常
} catch (ExecutionException e) {
    // 主线程在这里捕获线程内部的异常
    System.out.println("感知到异常：" + e.getCause());
}
```

✅ **面试必说**：

- `execute()` 不会把异常抛给主线程
- `submit()` 会把异常存到 Future 中
- **主线程调用 get () 才能拿到异常**

------

## 3. **自定义 ThreadFactory + 未捕获异常处理器（通用优雅）**

给所有线程统一设置异常处理器，**全局生效**。

java



运行









```
ThreadFactory factory = r -> {
    Thread thread = new Thread(r);
    // 设置未捕获异常处理器
    thread.setUncaughtExceptionHandler((t, e) -> {
        System.out.println("线程 " + t.getName() + " 异常：" + e);
    });
    return thread;
};

ExecutorService executor = new ThreadPoolExecutor(..., factory, ...);
executor.execute(() -> {
    int i = 1 / 0; // 异常会被处理器捕获
});
```

**注意**：只对 `execute()` 有效，对 `submit()` 无效。

------

## 4. **重写线程池 afterExecute 钩子方法（最高级）**

通过**钩子方法**统一捕获所有任务的异常。

java



运行









```
ThreadPoolExecutor executor = new ThreadPoolExecutor(...) {
    @Override
    protected void afterExecute(Runnable r, Throwable t) {
        super.afterExecute(r, t);
        if (t != null) {
            // 主线程逻辑感知异常
            System.out.println("线程池捕获异常：" + t);
        }
    }
};
```

✅ **企业生产标准方案**

# 面试标准答案（背这段就够）

1. **线程池默认会吞掉线程异常**，主线程无法直接感知。

2. **Runnable + execute()**：异常直接丢失，必须用 try-catch 或 UncaughtExceptionHandler。

3. **Callable + submit()**：异常会被存到 Future 里，**主线程调用 get () 才能捕获**。

4. 通用方案：

   - 任务内部 try-catch
   - Future.get () 捕获（最常用）
   - 自定义线程异常处理器
   - 重写 afterExecute 钩子

   

------

## 最简单记忆口诀

**execute 吞异常，submit 存异常；get 方法一调用，异常就能被感知。**
